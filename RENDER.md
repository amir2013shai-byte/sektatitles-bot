# 🚀 Деплой @Sekta_titles_bot на Render — пошаговая инструкция

> ⚠️ **Важно (ноябрь 2026): адреса Render блокируются из России** — сайт и сами сервисы
> `*.onrender.com` не открываются без VPN. Эта инструкция остаётся для случаев, когда у вас есть VPN
> или вы не в РФ. Для России используйте **Amvera** — см. [HOSTING.md](HOSTING.md).

Время: **15–20 минут**. Нужны: аккаунт GitHub и аккаунт Render (оба бесплатные).
Итог: бот работает 24/7 в облаке, ваш компьютер может быть выключен.

## Шаг 1. Аккаунт GitHub и репозиторий

1. Зарегистрируйтесь на [github.com](https://github.com) (если ещё нет аккаунта).
2. Нажмите **+** (справа вверху) → **New repository**.
3. Заполните:
   - **Repository name:** `sektatitles-bot`
   - **Private** — поставьте галочку (код будет виден только вам).
   - **Add a README file** — можно не ставить галочку.
4. **Create repository**.

## Шаг 2. Загрузите файлы проекта

1. На странице пустого репозитория нажмите ссылку **uploading an existing file**
   (или: **Add file** → **Upload files**).
2. Откройте на компьютере папку `titlebot` (она лежит в рабочей папке этого проекта — скачайте её себе).
3. **Выделите всё содержимое папки** (файлы и подпапку `handlers`, `tests`) и перетащите в окно браузера.
   Папки перетаскивать можно — GitHub сохранит структуру.
4. Проверьте, что **в списке НЕТ файла `.env`** и папки `data/`.
   (Я его уже удалил из проекта, но если у вас есть локальная копия — не загружайте.)
5. Внизу нажмите зелёную кнопку **Commit changes**.

Должно получиться так:

```
sektatitles-bot/
├── main.py  config.py  db.py  services.py  catalog.py  ui.py
├── middlewares.py  backup.py
├── handlers/  (common.py, shop.py, style.py, admin.py, __init__.py)
├── tests/     (4 файла тестов)
├── requirements.txt  render.yaml  Procfile  Dockerfile
├── docker-compose.yml  fly.toml  .env.example  .gitignore
└── README.md
```

## Шаг 3. Регистрация на Render

1. Откройте [render.com](https://render.com) → **Get Started** → **GitHub** → разрешите доступ.
2. Подтвердите e-mail, если попросит.

## Шаг 4. Создайте сервис через Blueprint (самый простой путь)

1. В панели Render: **+ New** → **Blueprint**.
2. **Connect a repository** → выберите `sektatitles-bot` → **Connect**.
3. Render найдёт файл `render.yaml` и покажет сервис `titlebot` с планом **Free**.
4. Нажмите **Apply** / **Create**.

<details>
<summary><b>Если Blueprint недоступен — создайте Web Service вручную</b></summary>

**+ New** → **Web Service** → выберите репозиторий → и заполните:

| Поле | Значение |
|---|---|
| Name | `sektatitles-bot` |
| Language / Runtime | **Python 3** |
| Branch | `main` |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `python main.py` |
| Instance Type | **Free** |
| Health Check Path | `/` |

Затем **Create Web Service**.
</details>

## Шаг 5. Заполните переменные окружения

Render спросит их сразу (Blueprint) или после создания: **Environment** → **Add Environment Variable**.

| Key | Value | Обязательно |
|---|---|---|
| `BOT_TOKEN` | токен из @BotFather | ✅ |
| `OWNER_IDS` | `6456120346` | ✅ |
| `WEBHOOK_SECRET` | ваша придуманная строка | ✅ |
| `PYTHON_VERSION` | `3.12.6` | желательно |
| `AUTO_BACKUP_HOURS` | `6` (бэкап базы вам в личку каждые 6 ч) | желательно |
| `START_COINS` | `50` | по желанию |
| `DAILY_BONUS` | `75` | по желанию |
| `PAYMENTS_ENABLED` | `1` (звёзды ⭐ включены) | по желанию |

> `PUBLIC_BASE_URL` **не нужен** — Render сам передаёт адрес сервиса в переменной `RENDER_EXTERNAL_URL`,
> бот берёт его и автоматически ставит вебхук.
>
> `DATABASE_PATH` уже прописан в `render.yaml` (`data/titlebot.sqlite3`), менять не надо.

Нажмите **Save Changes** — Render начнёт сборку.

## Шаг 6. Дождитесь сборки (2–4 минуты)

Смотрите вкладку **Logs**. Успешный запуск выглядит так:

```
Установка зависимостей...
2026-11-16 ... INFO titlebot: Webhook установлен: https://sektatitles-bot.onrender.com/telegram
2026-11-16 ... INFO titlebot: HTTP-сервер слушает 0.0.0.0:10000
==> Your service is live 🎉
```

Ключевые строки — **«Webhook установлен»** и **«Your service is live»**.

Проверка в браузере: откройте `https://<ваш-адрес>.onrender.com/` — должно быть написано `ok`.

## Шаг 7. Включите чтение сообщений в группах (обязательно!)

1. @BotFather → `/setprivacy` → выберите **@Sekta_titles_bot** → **Disable**.

Без этого бот не видит сообщения в группах: промокоды, написанные участниками, не сработают,
и база участников для массовой выдачи не наполнится.

## Шаг 8. Проверьте бота в Telegram

1. Откройте **@Sekta_titles_bot** → `/start` → должно появиться меню с кнопками.
2. `/shop` → выберите титул → купите за монеты.
3. `/style` → выберите эмодзи → он применится к надетому титулу.
4. `/admin` → **📢 Массовая выдача** → титул → аудитория → подтверждение.
5. `/newpromo` → создайте код (например `SEKTA2026`, монеты, 100 активаций) и проверьте его.
6. `/backup` — база прилетит вам в личку файлом.
7. Добавьте бота в группу **администратором** с правом **«Добавлять администраторов»**,
   напишите в группе `/sync`, затем `/mass` — титулы встанут и в базе, и как настоящие кастомные титулы.

## Шаг 9. Смените токен на новый (важно для безопасности)

1. @BotFather → `/revoke` → **@Sekta_titles_bot** → скопируйте **новый** токен.
2. Render → ваш сервис → **Environment** → `BOT_TOKEN` → вставьте новый токен → **Save Changes**
   (сервис перезапустится автоматически, ~1 минута).
3. Убедитесь по логам, что снова появилось «Webhook установлен».

## Шаг 10. Не давайте боту засыпать

На бесплатном плане Render останавливает сервис после ~15 минут без запросов — бот «просыпается»
за 30–50 секунд при первом сообщении. Чтобы этого не было:

1. Откройте [cron-job.org](https://cron-job.org) (или [uptimerobot.com](https://uptimerobot.com)) → регистрация.
2. **Create cronjob**:
   - **URL:** `https://<ваш-адрес>.onrender.com/health`
   - **Schedule:** каждые **10 минут**
   - Сохраните.
3. Готово: пинг держит сервис активным, бот отвечает мгновенно.

## 🔄 Как обновлять код после изменений

**Через GitHub (просто):** откройте файл в репозитории → карандаш ✏️ → правки → **Commit changes** → Render
пересобирает автоматически (1–3 минуты).

**Если файлов много:** **Add file** → **Upload files** → перетащите → **Commit changes**.

Цены титулов, бонусы и редкости можно менять без правки кода — командами бота:
`/addtitle` (новый титул), `/newpromo` (промокод), `/grant` (выдача).

## 💾 Про данные: бесплатный Render стирает диск

У Free-плана нет постоянного диска: при каждом перезапуске/редеплое база обнуляется.
Защита уже встроена:

- `AUTO_BACKUP_HOURS=6` — бот сам присылает вам файл базы в личку каждые 6 часов;
- `/backup` — бэкап в любой момент;
- `/restore` — ответьте на файл базы командой `/restore`, и всё вернётся.

Если данные критичны — два варианта:

1. **Render Disk** (платный план Starter, ~$7/мес) → **Settings** → **Disks** → Add Disk,
   mount path `/var/data`, затем `DATABASE_PATH=/var/data/titlebot.sqlite3`.
2. **Fly.io** с бесплатным volume (`fly.toml` уже в проекте) — база не стирается.

## 🧯 Если что-то не работает

| Симптом | Что делать |
|---|---|
| Сборка падает на `pip install` | Environment → `PYTHON_VERSION` = `3.12.6` → Save |
| В логах `Не задан BOT_TOKEN` | переменная не добавлена или не сохранена → добавьте → Save |
| `No open ports detected` | Start Command должен быть `python main.py` (не `uvicorn`) |
| В логах `401` по вебхуку | `WEBHOOK_SECRET` менялся → Manual Deploy → **Clear build cache & deploy** |
| Бот молчит, логов нет | проверьте `/health` в браузере; если долго грузится — сервис спал, включите cron-пинг |
| Промокоды в группе не работают | privacy mode не выключен (шаг 7) или бот не админ в группе |
| Данные пропали после рестарта | это Free-план → `/restore` из последнего бэкапа |
