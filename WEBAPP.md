# Большое обновление TitleBot

В обновлении добавлены игры, рынок титулов, квесты, сезоны, генераторы и витрина. Все ставки — только внутриигровые 🪙; казино не принимает и не выплачивает реальные деньги.

## Команды участника

| Команда | Что делает |
|---|---|
| `/quests` | Видимые задания, прогресс и получение наград |
| `/dice 100` | Кубик против бота, ставка 10–10 000 🪙; ничья проигрывает |
| `/coin 100 решка` | Монетка, угадать сторону |
| `/duel 100` ответом на сообщение | Вызов участника на ставку; победитель забирает банк |
| `/craft rare` | Три титула одной редкости → один случайный титул следующей редкости |
| `/lootbox` | Лутбокс за 500 🪙; обычный 55%, редкий 27%, эпический 12%, легендарный 5%, мифический 1% |
| `/auction` | Аукцион, ставки `/bid ID СУММА` |
| `/auction sell CODE ЦЕНА ЧАСЫ` | Выставить принадлежащий вам, не надетый титул на аукцион |
| `/rentals` | Список предложений аренды |
| `/rent sell CODE ЦЕНА ЧАСЫ` | Временно сдать свой титул (1–168 часов) |
| `/rent buy ID` | Арендовать титул; он автоматически вернётся владельцу по сроку |
| `/trade @партнёр МОЙ_КОД ЕГО_КОД` | Предложить обмен; подтвердить может только получатель |
| `/season` | Таблица текущего сезона |
| `/showcase` | Открыть коллекцию карточками в Telegram WebApp |

## Активность, квесты и сезоны

- Обычные текстовые сообщения в группах дают прогресс видимым заданиям и очки сезона; команды и личные сообщения не учитываются.
- В списке `/quests` отображаются только обычные задания. Скрытые задания, их прогресс и названия не появляются в интерфейсе до выполнения; после выполнения бот сообщает о награде.
- Титулы за активность выдаются автоматически за пороги сообщений и за 7/30 разных активных дней.
- Очки сезона: сообщение +1 (не более 40 в день), победа в дуэли +5, задание +10, выигранный аукцион +15. Победителям сезона начисляются монеты и призовые титулы.
- Владелец запускает сезон командой `/season start Название 30`, завершает `/season end`.

Для учёта сообщений в группах откройте @BotFather → `/setprivacy` → выберите бота → **Turn off**. Telegram иначе скрывает от бота обычные сообщения. Бот должен быть добавлен в группу.

## Команды владельца

- `/addtitle` — добавить титул вручную.
- `/aititle описание [редкость]` — создать титул тематическим генератором. Без `OPENAI_API_KEY` работает локальная генерация; с ключом можно использовать OpenAI API (тариф провайдера может быть платным).
- `/aiemoji тема` — добавить тематические эмодзи в `/style`.
- `/aipromo тема [количество] [монеты]` — сгенерировать пакет одноразовых промокодов.
- `/newpromo`, `/delpromo` — обычные промокоды; доступ только владельцу.
- `/auction sell` и `/rent sell` доступны участнику только для его собственных титулов; арендованные титулы нельзя повторно сдавать, передавать или использовать в крафте.

Наградные титулы скрыты из публичного каталога и лутбоксов. Публичный `/titles` не показывает титулы секретных достижений.

## GitHub Pages для витрины

Статическая WebApp показывает профиль, титул, коллекцию, баланс и сезонные очки. Она не принимает платежи и не изменяет данные.

1. В репозитории откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. В **Actions → Publish collection showcase** запустите **Run workflow** (или запушьте изменение в `webapp/`).
4. Дождитесь зелёного шага Publish. Адрес витрины:

   `https://amir2013shai-byte.github.io/sektatitles-bot/`

Workflow публикует содержимое `webapp/` автоматически после каждого изменения в этой папке. Для показа кнопки `/showcase` в GitHub Actions задан `WEBAPP_URL`.

## Деплой и база

Бот по-прежнему работает через GitHub Actions циклами примерно по 5 ч 45 мин, затем перезапускается; состояние хранится в `data/titlebot.sqlite3` и коммитится workflow. Обновляющий скрипт не включает `.env` и `data/` и не использует force-push.

Если репозиторий переименован, обновите `WEBAPP_URL` в `.github/workflows/titlebot.yml`. Нужна помощь с деплоем — используйте новый GitHub token только локально как `GH_TOKEN`, не отправляйте его в публичный чат.
