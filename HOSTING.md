# 🌍 Где запустить бота: что работает из России

Проверено на ноябрь 2026. Ситуация такая, что почти все «модные» бесплатные площадки из РФ
недоступны — их адреса блокируются. Поэтому таблица честная:

| Площадка | Доступ из РФ | Цена | Карта РФ | Засыпает? | Вердикт |
|---|---|---|---|---|---|
| ~~Render~~ | ❌ **заблокирован с 09.2026** (их IP-диапазон) | — | — | — | не подходит |
| ~~PythonAnywhere~~ | ❌ заблокирован с 12.2025 (хостится в AWS) | — | — | — | не подходит |
| ~~Bot-Hosting.net~~ | ❌ не открывается из РФ | — | — | — | не подходит |
| ~~Bothost.ru~~ | ✅ | с 11.2026 только платно | да | нет | не подходит |
| ~~FadeHost~~ | ⚠️ зарубежный, может блокироваться | 0 ₽ | — | нет | рискованно |
| ~~FPS.ms free~~ | ⚠️ зарубежный | 0 ₽ (128 МБ) | — | нет | **не хватит RAM** |
| **Amvera** ⭐ | ✅ российский, работает | 111 ₽ приветственных ≈ 2 недели, далее **290 ₽/мес** | **да, МИР** | **нет** | **рекомендую** |
| **VPS в РФ** (Timeweb, Aeza, RuVDS) | ✅ | **от ~150–250 ₽/мес** | да | нет | если нужен полный контроль |

**Про память — важное:** aiogram с зависимостями занимает **~170 МБ RAM** (замерил: пустой Python 8 МБ,
Python + aiogram 162 МБ). Поэтому бесплатные тарифы на 128 МБ (FPS.ms free) физически не подходят:
бот будет убит по OOM. Минимум — **256 МБ**, комфортно — **512 МБ**.

**Исключение — GitHub Actions:** это единственный полностью бесплатный бессрочный вариант, доступный из РФ
(публичный репозиторий = безлимитные минуты). Бот работает циклами по ~6 часов с паузами 10–20 минут.
Инструкция: **[GITHUB_ACTIONS.md](GITHUB_ACTIONS.md)**.

**Вывод:** бесплатного 24/7 без пауз для этого бота в РФ сейчас нет. Самый дешёвый надёжный вариант —
**Amvera: ~290 ₽/мес** (это меньше, чем 10 ₽ в день), оплата картой МИР, бот не засыпает,
база хранится на постоянном диске. Первые ~2 недели бесплатно за счёт приветственного баланса.

# 📦 FadeHost: инструкция (если сайт у вас открывается)

> ⚠️ Площадка зарубежная — из РФ может не открываться. Используйте, только если проверили доступ.

## Шаг 1. Регистрация

1. Откройте [fadehost.com](https://fadehost.com) → **Sign up** (или сразу [laplace.fadehost.com/register](https://laplace.fadehost.com/register)).
2. E-mail + пароль → подтвердите письмо. **Карта не нужна.**

## Шаг 2. Создайте приложение

1. В панели: **Apps** → **Host something** → выберите **Telegram bot**.
2. Способ доставки кода — **Upload your code** (загрузить архив/файлы; GitHub не нужен).
3. Имя — например `sektatitles`. Тариф — **Free**.

## Шаг 3. Загрузите файлы бота

Загрузите **всё содержимое папки `titlebot`**, сохранив структуру:

```
main.py  config.py  db.py  services.py  catalog.py  ui.py  middlewares.py  backup.py
handlers/  (common.py, shop.py, style.py, admin.py, __init__.py)
requirements.txt   runtime.txt
```

`render.yaml`, `fly.toml`, `Dockerfile`, `docker-compose.yml`, папки `tests/` и `data/` — можно не загружать,
они нужны только для других площадок. Файл `.env` загружать **нельзя** — токен вводится в панели (шаг 4).

## Шаг 4. Переменные окружения

В настройках приложения → **Environment variables** добавьте:

| Key | Value |
|---|---|
| `BOT_TOKEN` | `8884403083:AAFP01Fb17trfjZn8qdfN_UopcsdeV7ZY-U` |
| `OWNER_IDS` | `6456120346` |
| `START_COINS` | `50` |
| `DAILY_BONUS` | `75` |
| `PAYMENTS_ENABLED` | `1` |
| `AUTO_BACKUP_HOURS` | `24` |

`PUBLIC_BASE_URL` **не задавайте** — бот запустится в режиме polling, вебхук и домен не нужны
(на бесплатном тарифе FadeHost вебхуки платные, нам они и не нужны).

## Шаг 5. Команда запуска

- **Start command / Start file:** `python main.py`
- **Python version:** 3.12 (в проекте уже есть `runtime.txt` с `python-3.12.6`).
- **Install:** `pip install -r requirements.txt` (обычно определяется сам по `requirements.txt`).

## Шаг 6. Запуск и проверка

1. Нажмите **Deploy / Start**. Живая консоль покажет:

```
INFO titlebot: Запуск в режиме polling (без PUBLIC_BASE_URL)
INFO aiogram.dispatcher: Run polling for bot @Sekta_titles_bot id=8884403083
```

2. В Telegram: **@Sekta_titles_bot** → `/start` → меню.
3. Проверьте: `/shop`, `/style`, `/admin`, `/newpromo`, `/backup` (база придёт вам в личку файлом).

## Шаг 7. Обязательная настройка у @BotFather

`/setprivacy` → **Sekta_titles_bot** → **Disable** — иначе бот не видит сообщения в группах
(промокоды и сбор участников для массовой выдачи не работают).

Затем добавьте бота в группу **администратором** с правом **«Добавлять администраторов»** —
это нужно, чтобы титулы ставились как настоящие кастомные титулы админам.

## Шаг 8. Смените токен (он засветился в переписке)

1. @BotFather → `/revoke` → **Sekta_titles_bot** → скопируйте новый токен.
2. FadeHost → **Environment** → `BOT_TOKEN` → новый токен → **Save & redeploy**.

## Как обновлять код

- **Загрузка файлов:** панель → ваше приложение → **Files/Deploy** → загрузите изменённые файлы → redeploy.
- **Через GitHub (необязательно):** если позже захотите — подключите приватный репозиторий,
  каждый push будет деплоиться автоматически (в коде это уже поддержано через `render.yaml`/Procfile).
- Цены, титулы, промокоды меняются **без деплоя** — прямо в Telegram: `/addtitle`, `/newpromo`, `/grant`, `/mass`.

# 🔁 Если уже начали с Render

Ничего переделывать не надо: проект одинаково работает на всех площадках.

1. Деплойте тот же код на FadeHost или Bot-Hosting.net — **без** `PUBLIC_BASE_URL`.
2. Убедитесь, что старый сервис на Render **остановлен** (Suspended), иначе два процесса будут
   конкурировать за одни и те же апдейты Telegram (`Conflict: terminated by other getUpdates`).
3. Если база была на Render — `/backup` там, затем на новой площадке `/restore` ответом на файл.

## Что попробовать с Bothost бесплатно (2 минуты)

На их главной Starter ₽0 всё ещё указан, поэтому возможны два исхода:
1. В панели при создании бота выберите слева **Starter / ₽0** (иногда он не выбран по умолчанию,
   и форма сразу показывает баннер про платный тариф);
2. Если Starter выбрать нельзя — напишите их поддержке [@Bothostru](https://t.me/Bothostru):
   «На главной указан бесплатный Starter (1 бот, 256 МБ), но в форме создания бота требуется
   тариф Базовый. Бесплатный тариф больше не выдаётся?» Ответ решит вопрос за вас.

Если бесплатный Starter реально закрыт — переходите на Amvera (290 ₽/мес) или дешёвый VPS (150–250 ₽/мес).

## VPS за 150–250 ₽/мес: одна команда

Арендуйте минимальный VPS (1 ГБ RAM, Ubuntu 22.04+) — например PQ.Hosting (€1.7), Aeza, Zomro, Timeweb.
Затем загрузите файлы бота и запустите готовый скрипт:

```bash
# на своём компьютере: залить файлы на сервер
scp -r titlebot/* root@IP_СЕРВЕРА:/opt/titlebot/

# на сервере
cd /opt/titlebot && bash install_on_vps.sh
```

`install_on_vps.sh` сам поставит Python, создаст venv, установит зависимости, пропишет `.env`,
зарегистрирует systemd-сервис с автоперезапуском, запустит бота и проверит в логах строку
«Run polling for bot». Дальше он работает 24/7 и поднимается после перезагрузки сервера.

# 🧯 Частые ошибки именно на этих площадках

| Симптом | Причина и решение |
|---|---|
| `ModuleNotFoundError: No module named 'aiogram'` | не выполнился `pip install -r requirements.txt` → пропишите команду установки вручную в настройках |
| `SyntaxError` при старте | старая версия Python → в проекте есть `runtime.txt` (`python-3.12.6`), укажите 3.12 в панели |
| `Conflict: terminated by other getUpdates` | бот уже запущен в другом месте (Render/локально) → остановите второй экземпляр |
| Процесс падает через минуту | скорее всего не задан `BOT_TOKEN` → смотрите консоль, там будет `Не задан BOT_TOKEN` |
| Данные пропали после деплоя | на площадке нет постоянной папки → включите `AUTO_BACKUP_HOURS=24` и восстанавливайте через `/restore` |
| Бот молчит в группе | privacy mode включён (шаг 7) или бот не админ в группе |
| Не ставится настоящий кастомный титул | у бота нет права «Добавлять администраторов» в этой группе |
