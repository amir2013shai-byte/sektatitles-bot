# 🆓 Бесплатный 24/7 через GitHub Actions (без карты, работает из РФ)

Единственный вариант, который **не стоит ни рубля бессрочно** и запускается из России без VPN и карты.
Идея: GitHub Actions — это бесплатные виртуальные машины. Публичному репозиторию дают **безлимитные минуты**,
поэтому бота можно держать в них постоянно.

Как это устроено:

```
каждые 6 часов GitHub запускает job
        ↓
бот работает ~5 ч 45 мин (polling к Telegram)
        ↓
job сохраняет базу обратно в репозиторий (коммит)
        ↓
через ~15 минут стартует следующий job — и так круглосуточно
```

Файл с этой схемой уже готов: `.github/workflows/titlebot.yml`.

---

## Плюсы и минусы (честно)

| ✅ Плюсы | ⚠️ Минусы |
|---|---|
| 0 ₽ навсегда, карта не нужна | раз в 6 часов пауза ~10–20 минут (бот временно не отвечает) |
| работает из РФ | GitHub может задержать запуск по расписанию на 5–15 минут |
| токен хранится в Secrets, в коде его нет | данные живут в файле БД внутри репозитория (коммитится каждые 6 часов) |
| ничего администрировать не надо | это «народный» способ: GitHub может ограничить, если репозиторий станет популярным |
| база не теряется между запусками | история коммитов растёт (по одному коммиту в 6 часов, это мелочь) |

**Итог:** идеально для чата на 50–500 человек. Если нужна работа без пауз 24/7 — только платный хостинг
(Amvera 290 ₽/мес или VPS 150–250 ₽/мес, см. [HOSTING.md](HOSTING.md)).

## Шаги (5–10 минут, всё в браузере)

### 1. Создайте публичный репозиторий

1. Откройте [github.com/new](https://github.com/new) (нужен аккаунт GitHub — бесплатно).
2. **Repository name:** `sektatitles-bot`
3. Тип: **Public** ← обязательно, иначе Actions дадут только 2000 минут в месяц (этого мало для 24/7).
4. **Create repository**.

> Публичный — это нормально: код видят все, а токен лежит не в коде, а в Secrets (шаг 3).

### 2. Загрузите файлы бота

**Вариант А — перетащить (проще с компьютера):**
1. На странице репозитория: **Add file** → **Upload files**.
2. Перетащите из папки `titlebot`: `main.py`, `config.py`, `db.py`, `services.py`, `catalog.py`,
   `ui.py`, `middlewares.py`, `backup.py`, `requirements.txt`, папку `handlers`, папку `.github`
   (в ней лежит готовая схема запуска).
3. **НЕ загружайте:** `.env`, папку `data`, `__pycache__`.
4. Внизу: **Commit changes**.

**Вариант Б — файл запуска вручную (удобно с телефона):**
1. **Add file** → **Create new file**.
2. В поле имени введите ровно: `.github/workflows/titlebot.yml`
   (слеши создадут папки автоматически).
3. Вставьте содержимое файла `.github/workflows/titlebot.yml` из проекта.
4. **Commit changes**.

### 3. Положите токен в Secrets

1. В репозитории: **Settings** → **Secrets and variables** → **Actions**.
2. **New repository secret** → имя `BOT_TOKEN`, значение:
   `[токен из @BotFather]` → **Add secret**.
3. Ещё один секрет: имя `OWNER_IDS`, значение `6456120346`.

### 4. Включите Actions и запустите

1. Вкладка **Actions** → если просят, нажмите **I understand my workflows, go ahead and enable them**.
2. Слева выберите **TitleBot** → справа **Run workflow** → **Run workflow**.
3. Через 1–2 минуты откройте запущенный job → шаг **Запуск бота**.
   Успех выглядит так:

```
INFO titlebot: Запуск в режиме polling (без PUBLIC_BASE_URL)
INFO aiogram.dispatcher: Run polling for bot @Sekta_titles_bot id=8884403083
```

4. Проверьте бота в Telegram: `/start`, `/shop`, `/style`, `/admin`, `/newpromo`, `/backup`.

### 5. Готово — дальше всё само

Job работает ~5 ч 45 мин, затем:
- сохраняет базу коммитом `db: 2026-11-17T06:30:00Z`;
- следующий запуск стартует по расписанию `5 */6 * * *` (00:05, 06:05, 12:05, 18:05 UTC).

Менять титулы, цены, промокоды можно прямо в Telegram (`/addtitle`, `/newpromo`, `/grant`, `/mass`) —
код менять не нужно, база сохранится сама.

## Важные мелочи

- **Два экземпляра бота на одном токене = конфликт.** Если бот ещё крутится у меня в песочнице
  или на другом хостинге — напишите, я остановлю. В логах конфликт выглядит как
  `Conflict: terminated by other getUpdates`.
- **Токен засветился в переписке** — после проверки сделайте `/revoke` у @BotFather и обновите секрет
  `BOT_TOKEN` в GitHub (Settings → Secrets → Actions).
- **Первый запуск по расписанию** может произойти не сразу — GitHub ставит новые cron в очередь.
  Нажмите **Run workflow** вручную, чтобы бот поднялся немедленно.
- **Если Actions не запускаются**: проверьте, что репозиторий **публичный** и Actions включены
  (Settings → Actions → General → Allow all actions).
- **Хочу без пауз:** это только платные варианты — Amvera 290 ₽/мес, VPS 150–250 ₽/мес
  ([HOSTING.md](HOSTING.md)).

## Что я проверил

- Схема `.github/workflows/titlebot.yml` валидна (YAML разбирается, cron и таймауты на месте).
- Бот корректно завершается по `SIGINT` (именно так его останавливает `timeout` в workflow)
  и закрывает соединение с Telegram и БД — проверил локально.
- База после остановки сохраняется целиком (69 КБ), `wal_checkpoint` в workflow её «сжимает»
  перед коммитом.
- Лимиты GitHub: job максимум 6 часов, cron минимум 5 минут, публичные репозитории — безлимитные минуты.
