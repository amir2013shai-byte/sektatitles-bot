# 🎖 TitleBot — титулы, промокоды, покупки и кастомные эмодзи

Telegram-бот на Python (aiogram 3 + SQLite), который **работает круглосуточно на бесплатном хостинге**, а не на вашем компьютере.

Что умеет:

| Возможность | Как это выглядит |
|---|---|
| 🎭 **Титулы** | Каталог из 17 титулов (5 редкостей), коллекция у каждого пользователя, «надеть/снять» |
| 🛒 **Покупка титулов** | За игровые монеты 🪙 и за звёзды Telegram ⭐ (реальные платежи, без платёжного провайдера) |
| 💰 **Монеты** | Бонус дня, награды админов, промокоды |
| 🎁 **Промокоды** | Монеты / титул / и то и другое, лимит активаций, срок жизни, отключение |
| 📢 **Массовая выдача** | Всем в чате, только админам, всем пользователям бота или только покупателям — в 3 клика |
| 🎨 **Кастомизация эмодзи** | Свой эмодзи к титулу из базового набора **и из любого набора премиум-эмодзи Telegram** |
| 🏆 **Топы** | Богачи и коллекционеры чата |
| 💾 **Бэкапы** | База в один клик улетает владельцу в личку, восстанавливается ответом на файл |
| ⚙️ **Админка** | Статистика, каталог, выдача/отзыв, создание промокодов — всё внутри Telegram |

Всё протестировано локально: 4 набора тестов (логика, бэкапы, Telegram-слой с фейковым API, HTTP/вебхук).

## 🚀 Быстрый старт (10–15 минут, без своего сервера)

> 📘 **Инструкции по деплою:** [GITHUB_ACTIONS.md](GITHUB_ACTIONS.md) — 🆓 **полностью бесплатно и работает из РФ** (GitHub Actions, без карты). [HOSTING.md](HOSTING.md) — платные и зарубежные варианты, что заблокировано в РФ. [RENDER.md](RENDER.md) — Render по шагам.

### Шаг 1. Создайте бота у @BotFather

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → имя и username.
2. Скопируйте **токен** вида `1234567890:AAH...`.
3. Настройки группы:
   - `/setprivacy` → выберите бота → **Disable** (чтобы бот видел сообщения для промокодов и сбора участников);
   - `/setjoingroups` → **Enable**;
   - `/setcommands` — необязательно, бот сам выставит команды при старте.

### Шаг 2. Узнайте свой Telegram ID

Напишите [@userinfobot](https://t.me/userinfobot) — он пришлёт число (например `123456789`). Это ваш `OWNER_IDS`.

### Шаг 3. Залейте код на GitHub

1. Создайте пустой репозиторий на github.com (можно приватный).
2. Загрузите туда папку `titlebot` (кнопка **uploading an existing file** → перетащите файлы). Файл `.env` загружать **не нужно** — секреты вводятся в панели хостинга.

### Шаг 4. Задеплойте на Render (бесплатно)

1. [render.com](https://render.com) → регистрация через GitHub.
2. **New** → **Blueprint** → выберите ваш репозиторий (Render сам прочитает `render.yaml`).
3. Render спросит переменные:
   - `BOT_TOKEN` — токен из шага 1;
   - `OWNER_IDS` — ваш ID из шага 2;
   - `WEBHOOK_SECRET` — Render сгенерирует сам.
4. Нажмите **Apply**. Через 2–3 минуты сервис поднимется, адрес будет вида `https://titlebot-xxxx.onrender.com`.
5. Ничего больше вписывать не нужно: бот сам берёт адрес из `RENDER_EXTERNAL_URL` и ставит вебхук при старте.

Проверьте: в браузере `https://ваш-адрес.onrender.com/` должно вернуть `ok`.

> Альтернативы: **Railway** (`Procfile` уже в проекте), **Fly.io** (`fly.toml` + volume — база не стирается), **свой VPS** (`docker-compose.yml`). Подробности — ниже.

### Шаг 5. Добавьте бота в чат

1. Добавьте бота в группу и **сделайте администратором** — обязательно включите право **«Добавлять администраторов»** (только с ним бот может ставить настоящие кастомные титулы админам).
2. В группе: `/admin` → **📢 Массовая выдача** → выберите титул → аудиторию → подтвердите.

### Шаг 6. Не давайте боту «засыпать» (важно для бесплатного Render)

Бесплатный Render усыпляет сервис через ~15 минут без запросов. Заведите бесплатный пинг:

- [cron-job.org](https://cron-job.org) или [uptimerobot.com](https://uptimerobot.com) → HTTP-мониторинг `https://ваш-адрес.onrender.com/health` каждые 10 минут.

Бот будет просыпаться сам и отвечать без задержек.

## 🎮 Что видит обычный пользователь

- `/start` — меню: профиль, магазин, эмодзи, промокод, топ, бонус дня.
- `/shop` — карточки титулов: цена в 🪙, кнопка покупки, оплата ⭐ звёздами.
- `/style` — выбор эмодзи: он применяется к любому надетому титулу (премиум-эмодзи видны тем, у кого есть Telegram Premium; остальные увидят обычный фолбэк).
- `/promo КОД` или просто отправьте код сообщением — награда придёт сразу.
- `/profile`, `/top`, `/daily`.

## 👑 Команды администратора чата

| Команда | Что делает |
|---|---|
| `/admin` | Админ-панель с кнопками |
| `/mass` | Массовая выдача: титул → аудитория (чат / админы / все юзеры бота / покупатели) → подтверждение |
| `/grant CODE` | Выдать титул **ответом** на сообщение участника |
| `/grant @username CODE` | Выдать по юзернейму |
| `/revoke CODE` | Забрать титул (ответом на сообщение) |
| `/newpromo` | Мастер создания промокода (4 шага) |
| `/delpromo КОД` | Отключить промокод |
| `/addtitle` | Добавить титул: `код \| название \| редкость \| эмодзи \| цена_монеты \| цена_звёзды \| тираж` |
| `/loademoji имя_набора` | Импорт премиум-эмодзи из набора Telegram |
| `/sync` | Подтянуть админов чата в базу (для массовой выдачи) |
| `/titles` | Список кодов титулов |
| `/stats` | Статистика |
| `/backup`, `/restore` | Бэкап базы в личку / восстановление (только `OWNER_IDS`) |

**Права:** в группе команды доступны админам чата, в личке — только `OWNER_IDS`.

### Пример жизненного цикла промокода

```
/newpromo
→ код: DRAGON2026
→ что даёт: 3 (монеты + титул)
→ значение: dragon 500
→ активаций: 100
```
Бот создал код. Отправьте его в чат или канал — кто первый пришлёт его боту, получит 500 монет и титул «Дракон». После 100 активаций код отключится сам.

### Массовая выдача: как собрать аудиторию

1. `/sync` в группе — добавляет админов в базу.
2. Обычные участники попадают в базу автоматически, когда пишут в чате (privacy mode должен быть выключен).
3. `/mass` → титул → **«Всех в этом чате»** → **«Выдать N чел.»**
4. Повторная выдача не дублирует титулы — безопасно нажимать много раз.

## 💸 Звёзды Telegram (реальные платежи)

- Работает «из коробки»: `provider_token` пустой, валюта `XTR` — этого требует Telegram для цифровых товаров.
- Цена задаётся в каталоге (`stars` в титуле). Например `/addtitle` с `... | 0 | 250 | -1` = 250 ⭐.
- Доход в звёздах выводится через Fragment / тратится на рекламу в Telegram.
- Отключить: `PAYMENTS_ENABLED=0`.

## 🎨 Кастомные эмодзи

1. Найдите набор премиум-эмодзи: в Telegram → любой чат → эмодзи-панель → **«Премиум»**, либо откройте ссылку `t.me/addemoji/ИМЯ`.
2. В боте (под админом): `/loademoji ИМЯ_НАБОРА` — эмодзи появятся в разделе «Эмодзи».
3. Пользователь выбирает понравившийся — он подставляется во все его титулы.

Ограничения: премиум-эмодзи видны только пользователям с Telegram Premium, остальные получают обычный эмодзи-фолбэк (это поведение Telegram, не бота).

## ⚙️ Настройки (переменные окружения)

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `BOT_TOKEN` | — | токен из @BotFather |
| `OWNER_IDS` | — | ID владельцев через запятую (полный доступ + бэкапы) |
| `PUBLIC_BASE_URL` | пусто | задан → webhook; пусто → polling. На Render/Railway определяется автоматически |
| `WEBHOOK_SECRET` | `change-me` | секрет заголовка вебхука |
| `PORT` | `8080` | порт HTTP-сервера (Render задаёт сам) |
| `DATABASE_PATH` | `data/titlebot.sqlite3` | путь к базе |
| `AUTO_BACKUP_HOURS` | `0` | авто-бэкап владельцу раз в N часов |
| `START_COINS` | `50` | монеты новичку |
| `DAILY_BONUS` | `75` | бонус дня |
| `PAYMENTS_ENABLED` | `1` | 0 — выключить звёзды |
| `LOG_LEVEL` | `INFO` | логи |

Экономика правится там же: цены/редкости титулов — в `catalog.py` (или команда `/addtitle` без перезапуска).

## 🖥 Другие варианты хостинга

### VPS / любой сервер с Docker

```bash
git clone <ваш репозиторий> && cd titlebot
cp .env.example .env      # впишите BOT_TOKEN и OWNER_IDS
docker compose up -d --build
docker compose logs -f    # логи
```
База хранится в `./data` — переживает перезапуски. `PUBLIC_BASE_URL` оставьте пустым (polling).

### Fly.io (база на постоянном диске, бесплатный объём)

```bash
fly launch --no-deploy
fly volumes create titlebot_data --size 1
fly secrets set BOT_TOKEN=... OWNER_IDS=... WEBHOOK_SECRET=...
fly deploy
fly status                # узнайте адрес → fly secrets set PUBLIC_BASE_URL=https://...
```

### Railway

**New Project → Deploy from GitHub** → добавьте переменные `BOT_TOKEN`, `OWNER_IDS`, `PUBLIC_BASE_URL` (адрес выдаст Railway). `Procfile` уже в проекте.

### Локальный запуск (для теста)

```bash
pip install -r requirements.txt
cp .env.example .env && nano .env    # BOT_TOKEN, OWNER_IDS
python main.py
```

## 💾 Про потерю данных на бесплатных тарифах

У Render/Railway бесплатный диск **эфемерный**: при перезапуске контейнера база обнулится. Три способа защиты:

1. `AUTO_BACKUP_HOURS=6` — бот сам присылает вам файл базы в личку (только `OWNER_IDS`).
2. `/backup` — бэкап в любой момент; `/restore` ответом на файл — восстановление.
3. Fly.io с volume (`fly.toml`) или VPS — база на постоянном диске.

## 🆘 Если что-то не так

| Симптом | Причина / решение |
|---|---|
| `Не задан BOT_TOKEN` | переменная не добавлена в панели хостинга (после изменения — redeploy) |
| Бот молчит после деплоя | не задан `PUBLIC_BASE_URL` → бот в polling, а на Render это ломается: впишите адрес сервиса |
| `401` в логах вебхука | `WEBHOOK_SECRET` менялся — Telegram присылает старый; просто перезапустите сервис (вебхук переустановится) |
| Промокоды не активируются | у бота включён privacy mode (`/setprivacy` → Disable) или он не видит сообщения |
| Настоящие титулы админам не ставятся | боту не дали право «Добавлять администраторов» в этой группе |
| Массовая выдача находит мало людей | выполните `/sync`, участники попадают в базу после первого сообщения |
| Данные пропали после рестарта | эфемерный диск — включите `AUTO_BACKUP_HOURS` и восстанавливайте через `/restore` |
